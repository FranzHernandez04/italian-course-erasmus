# Test finale del corso

::: tip Verifica finale
20 domande a risposta multipla sul corso di italiano. **Nessun tempo limite**, **tentativi multipli accettati**. Alla fine vedrai subito il tuo punteggio e potrai rivedere le risposte.
:::

## Istruzioni

1. Inserisci **nome e cognome** all'inizio
2. Rispondi a tutte le 20 domande (una sola risposta corretta per ognuna)
3. Premi **Invia** alla fine
4. Visualizza il punteggio + risposte corrette/sbagliate
5. Puoi ripetere il test quante volte vuoi cliccando *"Invia un'altra risposta"*
